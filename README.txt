SPLIT — static website starter

Concept:
A social, mobile-friendly site built around quick opinions, polls, hot takes, rankings and tiny games. The goal is repeat visits and shareability rather than selling personal stories.

Included:
- index.html
- styles.css
- script.js

Important:
The current site is a front-end prototype. Votes and submissions are not stored on a server.
To turn it into a real community/product:
1. Add a database/authentication layer.
2. Add moderation and abuse controls.
3. Add analytics.
4. Add real accounts and persistent votes if desired.
5. Monetization options can include sponsorships, premium game packs, brand polls, memberships, or ads once there is meaningful traffic.
6. Do not collect sensitive personal data unnecessarily.
